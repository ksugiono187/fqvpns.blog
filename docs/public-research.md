# 公开线路与测速资料核对

检索日期：2026-10-12。范围：站方提交的29个品牌，不增加其他品牌。

## 已完成

- 逐品牌检索名称、别名、线路、测速、时间、工具与环境；同时查找对应公开资料与冲突说明。
- 29个记录在 src/data/research.ts 中保存，29个品牌页全部展示公开证据区域。
- /research/ 提供名称与状态筛选；/research-sources.csv 提供脱敏公开来源记录下载。
- 7个品牌保留有环境说明的第三方报告；14个资料不完整；7个资料存在冲突；1个本轮未找到合格测速。
- 10篇博客对具体公开材料作原创分析，正文明确测试由来源报告，未声称本站执行。

## 采用范围

部分来源有明确的测试日期、后端、线程与工具，选用少量与判断相关的原始字段。保留MB/s、KB/s、TLS RTT等口径及异常，不取不同批次峰值制造综合表现。微风、飞猫、灵猫、闪跃、无忧、光速和快狸的来源均可从品牌页直接访问。

“有环境说明”不等于证据真实性已经证明。本站没有获取私人订阅、登录服务、执行网络测试或取得可公开复现的完整机器日志。来源自称实测属于其声明，不能转成本站实测。单轮图不证明长期稳定、上传、丢包、全部平台支持或真实线路采购。

## 冲突处理

- Firefly：飞为名称与站方入口的身份对应待确认。
- 唯兔：有同域名入口线索，其他测速材料协议、节点规模不同，不能拼接。
- 极连：来源说明套餐图片包含极速云名称，身份冲突未解决。
- 梯子云：图片归属线索与自称官方账号身份待确认。
- 浪网：不同来源线路口径相互矛盾，未形成完整原始记录。
- 灵动：表格部分跨地区行重复同组数值，协议与线路口径有冲突。
- 隐形人：用户图片缺少完整来源链与订阅身份核验。

不将未知判定为服务差或不存在。缺失的字段在前台说明，不填虚构速度或物理线路。IPLC、IEPL、BGP宣传均没有本站独立物理验证。价格仍沿用原指定来源，不因本轮发现不同宣传价格就自动替换。

## 后续更新条件

需要明确入口对应关系、完整测试时刻与时区、设备及网络、带宽、工具版本与配置、任务和目标、原始成功失败记录。取得新材料时保留来源归属与变化理由，不能把查看日期替代实验日期。当前不生成跨品牌速度总榜。
